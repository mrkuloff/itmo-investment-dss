# itmo-investment-dss
Система поддержки принятия решений по инвестициям

## Сфера
Инвестиции

## Задача
Разработать СППР, помогающую компании сформировать портфель инвестиционных проектов при ограниченном бюджете

## Описание
Проекты отличаются ожидаемой доходностью, стоимостью, сроком реализации и уровнем риска. Необходимо обеспечить возможность сравнения проектов, анализа различных сценариев и формирования допустимого портфеля
